# MediaPlayer

Небольшой музыкальный плеер на Java Swing и BasicPlayer.

## Возможности

- добавление одного или нескольких аудиофайлов в плейлист;
- выбор трека, воспроизведение, пауза и остановка;
- переход к предыдущему и следующему треку;
- перемотка и регулировка громкости;
- отображение текущего времени и длительности.

Поддержка форматов зависит от Java Sound и библиотек проекта; MP3 поддерживается через BasicPlayer/MP3SPI. Для воспроизведения требуется рабочее аудиоустройство и графическая среда.

## Требования

- JDK 11 или новее;
- Maven 3.6 или новее.

## Сборка и тесты

```bash
mvn clean verify
```

## Запуск

```bash
java -jar target/MediaPlayer-1.0-SNAPSHOT-jar-with-dependencies.jar
```

В интерфейсе нажмите **«Добавить файлы…»**, выберите аудиофайлы и запустите выбранный трек. Интерфейс строится непосредственно в Java-коде, поэтому для Maven-сборки не требуется плагин IntelliJ GUI Designer.
